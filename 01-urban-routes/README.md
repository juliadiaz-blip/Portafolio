# Automatización de pruebas de Urban Routes

## Desafío

Automatizar pruebas de interfaz para validar diferentes funcionalidades de la aplicación web Urban Routes.

## Proceso

Desarrollé pruebas automatizadas utilizando Python, Selenium y Pytest. El proyecto utiliza una estructura basada en Page Object para organizar la interacción con la aplicación.

Las pruebas incluyen:

- Configuración de rutas.
- Selección de la tarifa Comfort.
- Registro del número de teléfono.
- Agregado de tarjeta de pago.
- Mensaje para el conductor.
- Selección de manta y pañuelos.
- Solicitud de helados.

## Resultado

Se implementaron pruebas automatizadas para validar diferentes escenarios de la aplicación y verificar el comportamiento de sus principales funcionalidades.

El proyecto permitió practicar la automatización de pruebas web, la organización del código mediante Page Object y la ejecución de pruebas con Pytest.

## Herramientas

- Python
- Selenium WebDriver
- Pytest
- Page Object Model
- ChromeDriver
